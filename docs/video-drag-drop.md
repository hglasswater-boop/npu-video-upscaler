# 動画のドラッグ＆ドロップ

- アプリの画面へ、存在するMP4/MKVファイルを1本ドロップして入力動画を選択する。日本語・空白・UNCパス、大文字の拡張子を扱う。
- ファイル選択と同じ入力欄の変更処理を使い、先頭60秒プレビューの保存先候補を更新する。利用者が編集した保存先は保持する。変換は自動開始しない。
- 複数ファイル、フォルダー、存在しないファイル、対象外の拡張子、Web URL、文字列だけのドロップは拒否する。変換中は入力を差し替えない。
- ドロップはコピー操作として扱う。元ファイルは移動・変更しない。保存先やモデル欄へのURL文字列挿入を防ぐ。
- Qtイベントの回帰テストとWindows CIで検証する。Explorerから配布版への実際の操作は別の実機検証項目とする。
