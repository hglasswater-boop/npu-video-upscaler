# Bundled media tools and NPU diagnostics — Issue #11

## Objective
Windows **installer** and portable ZIP run without Python, FFmpeg, or ffprobe preinstalled and without touching system PATH. The separately managed Intel NPU driver is **never** installed automatically. The local model ZIP is available as a consent-based download, not bundled.

## Runtime contract
- The packaged app resolves tools in `<installed-app>/_internal/media-tools/ffmpeg.exe` and `ffprobe.exe` (PyInstaller 6 one-dir extraction path `sys._MEIPASS`), treating the pair as a single requirement. The executable directory's `media-tools` path is an alternate for source/portable layouts when applicable.
- In **frozen** builds, never fall back to another FFmpeg/ffprobe on PATH if either bundled executable is absent. This avoids unintended versions, missing `libx264`, and malicious path shadowing.
- When **running from source** only, use an explicit developer-specified pair or discover both via `shutil.which`; fail if either is missing.
- All ffprobe, decoder and encoder command builders use the same resolved paths for the duration of one conversion. No global process PATH mutation.
- The selected FFmpeg must support decoding RGB24 and H.264 `libx264` encoding (including copying supported audio codecs). CI smoke verifies `ffmpeg -encoders` and `ffprobe -version`.
- Windows packaging CI downloads a vendor archive, verifies vendor-provided SHA256, preserves version/configuration/license notices, and stages `media-tools` inside `dist/NpuVideoUpscaler/_internal` **before** building Inno Setup and the portable ZIP.

## GPLv3 distribution gate
The Gyan FFmpeg essentials static build is licensed GPLv3 and includes `libx264`. FFmpeg's official legal guidance: https://ffmpeg.org/legal.html . The vendor documentation: https://www.gyan.dev/ffmpeg/builds/ . These are third-party binaries, not generated by our project's proprietary code. A public release bundling them requires verifying and providing their complete corresponding sources (including relevant third-party libraries/build scripts) and notices according to their licenses. At minimum publish license/configuration attribution and a matching corresponding-source bundle/offer accessible alongside binaries; **a casual link to upstream FFmpeg alone is not a substitute for corresponding sources**. If CI cannot validate a manifest of legally sufficient corresponding source materials, it must **fail closed before publishing a GitHub Release**. CI/PR packaging for internal inspection does not mean the release may be shipped to the public.

For development, use the **Gyan FFmpeg 9.0.2 Release Essentials ZIP**, whose observed SHA-256 is `60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`, fetched via HTTPS and checked against both that pin and the publisher's `.sha256` file. The stable URL can move to newer builds; if the hash changes, CI must fail until a deliberate supply-chain update. Record `ffmpeg -version`, its build configuration, upstream checksum, and included license documents. No rehosting without the release gate. A later iteration may adopt a vetted LGPL alternative that provides a supported H.264 codec and preserves quality with corresponding-license requirements met.

## Intel NPU driver help
- The NPU check is `"NPU" in ov.Core().available_devices`; **never** silently run model on CPU/GPU.
- On missing NPU, tell the user to inspect Device Manager → Neural processors → Intel AI Boost and use Intel's official driver page: https://www.intel.com/content/www/us/en/download/794734/intel-npu-driver-windows.html
- Driver installation/version selection is handled by Windows/OEM/Intel installer with their license prompts and possible reboot, not by this app. Distinguish missing NPU from model compilation failure.

## Tests and smoke checks
1. Pure tests exercise bundled path selection, missing/partial pair, source PATH fallback, command consistency and driver guidance.
2. Package CI runs frozen executable without FFmpeg on PATH and confirms embedded tools are executable; install smoke also validates tools at installed path.
3. Real FFmpeg A/V regression tests must still run.
4. Hardware smoke remains **open** on an actual Core Ultra 5 125H; CI cannot certify NPU performance.

## Release
Start PR without claiming completed public distribution. After GPL source compliance and packaging smoke pass, bump alpha version and use immutable new-tag workflow. Never replace an already published `v0.2.0a3` installer.
